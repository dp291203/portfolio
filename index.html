selected publications

  1. IEEE
    Emotion Detection in Multimodal Communication through Audio-Visual Gesture Analysis
    Divya Sai Aamuktha Pelluri and others
    In 2024 IEEE International Conference on Electronics, Computing and Communication Technologies (CONECCT), IISc Bangalore, India, Jul 2024
    Abs Bib HTML

    This research presents a multimodal emotion recognition system combining audio and visual gesture analysis using deep learning techniques. We developed an ECAPA-TDNN-based audio emotion recognition model achieving 97% accuracy on benchmark datasets and a body gesture emotion recognition pipeline using LSTM on pose-sequence data. By fusing audio and body modalities using Fuzzy Logic, we improved overall system robustness to 87%, demonstrating the effectiveness of multimodal approaches in emotion detection.
